# 管理接口与企业微信接入契约

## 通用约定

- 同源网站，全部管理接口前缀 `/api`，仅 GET/POST，不使用 URL 路径参数。
- 登录成功后使用 HttpOnly、SameSite=Strict Cookie，生产环境增加 Secure，8 小时有效；重启应用会使会话失效。
- 管理 POST 请求必须携带与 `PUBLIC_URL` 完全一致的 `Origin`。不开放跨域，不将管理凭证放入 localStorage。
- 身份验证失败返回 401，来源不合法返回 403；输入不合法返回 400；冲突或发送前置条件不满足返回 409。失败正文统一包含 `error` 中文说明。
- 所有标识使用 UUID 字符串或企业微信原始字符串，时间是 UTC ISO 8601 字符串。页面按浏览器本地时区展示，工作台统计以服务器时区划日。
- 列表 `page` 从 1 开始，固定 `pageSize=15`，返回 `{rows,total,page,pageSize}`，机器人配置列表同样分页。

## 认证与工作台

| 方法 | 地址 | 业务说明 |
| --- | --- | --- |
| GET | `/api/health` | 无需登录，返回应用进程的基础健康状态，不包含配置或密钥 |
| POST | `/api/login` | 输入管理员密码，创建控制台会话；15 分钟最多 15 次尝试 |
| GET | `/api/me` | 确认当前登录会话是否有效，返回管理员显示名 |
| POST | `/api/logout` | 销毁当前登录会话并清理 Cookie |
| GET | `/api/overview` | 返回机器人状态、今日消息统计、近 7 天接收趋势及实际运行配置 |

登录请求：`{"password":"管理员密码"}`。退出登录请求：`{}`。

“今日已回复”统计的是今日收到且当前状态为已回复的消息，不是所有今日发生的发送动作。零消息状态显示真实的 0，不提供虚构示例统计。

## 机器人管理

| 方法 | 地址 | 业务说明 |
| --- | --- | --- |
| GET | `/api/bots?page=1&search=&mode=` | 分页返回配置列表、启停状态、实际连接状态和回调地址，不返回凭证明文或密文 |
| POST | `/api/bots/save` | 新增或修改机器人；创建后默认停用，已启用的机器人必须先停用才能修改 |
| POST | `/api/bots/toggle` | 启用或停用指定机器人；长连接模式启动或关闭唯一的本地连接 |

URL 模式保存示例（全部为演示值）：

```json
{
  "name": "团队助手",
  "mode": "url",
  "token": "替换为合法Token",
  "aesKey": "替换为43位EncodingAESKey"
}
```

长连接模式保存：`name`、`mode="websocket"`、`botId`、`secret`。更新时额外传 `id`，同一模式下密钥留空保留原值；切换模式必须提供新模式对应的密钥。URL 模式不需要企业微信 BotID；回调地址中的 `bot` 为系统内部记录 ID，必须保留。长连接 BotID 唯一，禁止用两条配置争抢同一个企业微信机器人。

修改配置会使历史待回复消息失效，并停止未执行的 AI 排队任务，避免使用新凭证发送旧消息。配置更新也会清除 URL 验证状态，需要企业微信重新验证。

启停正文：`{"id":"机器人内部UUID","enabled":true}`。

机器人状态：

| 值 | 含义 |
| --- | --- |
| disabled | 已停用 |
| unverified | URL 已启用，等待企业微信验证 |
| verified | URL 验证曾成功；不代表持续网络探测成功 |
| connecting | 正在握手或认证 |
| connected | 已收到订阅成功确认 |
| reconnecting | 网络中断，正在退避等待 |
| auth_error | 认证失败，不自动反复重试 |
| displaced | 收到连接被替代事件，停止重连 |

## AI 模型配置

| 方法 | 地址 | 业务说明 |
| --- | --- | --- |
| GET | `/api/model` | 返回地址、模型、提示词、开关和密钥是否已配置；不返回 API Key |
| POST | `/api/model/save` | 保存全局模型配置；启用后新收到的文本消息自动入队生成回复 |
| POST | `/api/model/test` | 使用已保存配置请求一次简单回复，用于验证供应商可达性和参数兼容性；可能计费，每分钟最多 3 次 |

```json
{
  "enabled": true,
  "baseUrl": "https://供应商域名/v1",
  "model": "供应商支持的精确模型ID",
  "apiKey": "仅在保存时提交，留空保留原值",
  "prompt": "你是企业内部助手，请准确、简洁地回答。"
}
```

自动回复只处理文本消息，当前是单轮对话。队列持久化在 SQLite，最多并发 2 个模型请求；模型请求超时 60 秒，输出必须为 `choices[0].message.content` 非空字符串。模型基础地址只允许 HTTPS 与公网 IPv4 解析，不跟随重定向，不支持访问内网模型服务。

关闭自动回复后，不再执行队列生成；正在生成的任务结束后会再检查开关，关闭时不发送。重新开启会继续尚未过期的排队任务，已过期、已人工处理或机器人停用的任务会失败。AI 不自动读取历史上下文、不执行回复中的代码或工具调用。

## 消息和日志

| 方法 | 地址 | 业务说明 |
| --- | --- | --- |
| GET | `/api/messages?page=1&search=&bot=` | 分页查看接收记录，支持消息/发送者关键词和机器人内部 ID 筛选；返回 AI 任务状态与脱敏错误 |
| POST | `/api/messages/reply` | 对仍有效的待回复消息发送一次人工 Markdown 回复，与 AI 使用相同的并发提交控制和限流逻辑 |
| GET | `/api/audit?page=1` | 分页查看管理员和连接/回复操作事件；不返回凭证或 response_url |

人工回复正文：`{"id":"消息内部UUID","content":"Markdown回复内容"}`。回复最长 20480 UTF-8 字节，空白消息拒绝。

消息状态：`pending`（待回复）、`sending`（发送中）、`replied`（企业微信确认成功）、`unknown`（结果未确认，禁止自动重试）、`received`（仅接收/不可回复）、`expired`（凭证或回复时限已过）。`expired` 由查询时动态计算。

AI 状态：`queued`、`running`、`done`、`failed`。生成失败后若回复仍在有效期且状态为 pending，可以人工接管。人工先提交后，正在生成的 AI 结果会因消息状态不再 pending 而停止发送。

## 企业微信 URL 回调

固定路径：`/callbacks/wecom?bot=内部UUID`。该路径不使用管理 Cookie 或 Origin 检查，以企业微信签名作为身份验证依据。

- GET：读取 `msg_signature`、`timestamp`、`nonce`、`echostr`，签名正确后解密并原样返回明文，不加 JSON 引号、不加换行。
- POST：JSON 正文为 `{"encrypt":"密文"}`，签名来自查询参数。解密得到 JSON 后，按 `(机器人内部ID,msgid)` 唯一键排重并入库，然后返回 HTTP 200 空正文。
- 接收者 `ReceiveId` 按企业内部智能机器人要求固定为空；拒绝长度/填充非法数据。
- 时间戳允许与服务端相差 10 分钟以内，服务器需正确同步系统时间。
- `response_url` 只接受 `https://qyapi.weixin.qq.com/cgi-bin/aibot/response?response_code=...`，加密存储且不返回客户端。
- URL 回复使用原始 response_url POST Markdown。只要开始发送就不自动重复调用，收到 errcode=0 才标记成功。

## 已知边界与待实机验收

没有实现模板卡片/欢迎语即时响应、流式刷新、无回调主动群发和多媒体下载解密；相关事件仅保存基础记录。没有共享数据库、多实例租约、多租户、角色授权或集群会话。

官方文档已读取并据此实现协议，但真实机器人、实际模型供应商、宝塔反代与腾讯云出站网络仍需部署后验收。本地测试采用协议夹具和本地模拟 WebSocket 服务，不代表企业微信真实环境验收通过。
